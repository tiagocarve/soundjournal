❖ Architecture Refactoring Guide: Unifying Repository Files

To clean up code duplication across all standalone HTML tools in your repository, extract common styles and scripts into shared root assets (`styles.css` and `theme.js`).

STEP 01 // SHARED TOKENS
Extract Shared `styles.css`

Consolidate color palettes into a single root file so changing a theme updates all pages at once.

:root[data-theme="dark"] { --bg: #121212; --text: #a0a0a0; --accent: #0088cc; --border: #2e2e2e; } /* Link in head of every tool: */ <link rel="stylesheet" href="styles.css">
STEP 02 // UNIVERSAL THEMING
Extract Shared `theme.js`

Sync active theme choices seamlessly across tools using `localStorage`.

const themes = ["dark", "light", "sepia", "oled"]; function initTheme() { const t = localStorage.getItem('sj_theme') || 'dark'; document.documentElement.setAttribute('data-theme', t); } /* Include in every tool script */
